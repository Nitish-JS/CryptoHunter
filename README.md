# CryptoHunter

CryptoHunter is a React-based cryptocurrency tracker that displays prices, market data and charts for various coins.

## Installation

1. Ensure you have [Node.js](https://nodejs.org/) installed (Node 14 or later is recommended).
2. Install project dependencies:

```bash
npm install
```

## Running the Development Server

Start the application with:

```bash
npm start
```

This runs the app in development mode on [http://localhost:3000](http://localhost:3000). The page will reload if you make edits.

## Building for Production

To create an optimized production build:

```bash
npm run build
```

The build output will be placed in the `build/` directory.
